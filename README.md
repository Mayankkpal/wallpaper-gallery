# 🌿 Wallpaper Gallery

A beautiful and simple **Wallpaper Gallery website** featuring stunning nature wallpapers and a clean, modern design.

## ✨ Features

- 🌄 Beautiful nature wallpapers
- 🖼️ Responsive image gallery
- ⬇️ Download Wallpaper buttons
- 🕒 Live current-time display
- 📱 Mobile-friendly design
- ✨ Modern hover effects and animations
- 🌐 Hosted with GitHub Pages

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
- **Git & GitHub**
